## 📝 소개
Python Tkinter를 활용하여 제작한 GUI 기반 미니게임 런처입니다.
메인 런처에서 두 가지 게임을 선택하여 플레이할 수 있습니다.

<br />

## 📂 프로젝트 구조
```
GameProject/
├── mainWinodw.py           # 메인 런처 (게임 선택 화면)
├── pol_the.py              # 경찰과 도둑 게임
├── diff.py                 # 틀린그림찾기 게임
├── diff_level_choice.py    # 틀린그림찾기 난이도 선택
├── level_correct.py        # 레벨 정답 처리
├── play_page.py            # 게임 플레이 페이지
├── select_correct.py       # 정답 선택 처리
└── Images/                 # 게임 이미지 리소스
```
